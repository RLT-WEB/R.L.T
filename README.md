# SGA — Control de Tardanzas e Interacción

Aplicación web de una sola página para el registro y seguimiento de llegadas tarde de la
**I.E. Carlos Lleras Restrepo — Yopal, Casanare**.

## Archivos

- `index.html` — la aplicación (HTML, CSS y JavaScript en un solo archivo)
- `escudo.jpg` — escudo institucional (encabezado e ícono de la pestaña)

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub y sube `index.html`, `escudo.jpg` y este `README.md`.
2. Ve a **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. En uno o dos minutos la página quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Notas

- Los íconos se cargan desde [Lucide](https://lucide.dev) por CDN, por lo que se necesita conexión a internet.
- Los datos se guardan solo en memoria del navegador: al recargar la página vuelven a los datos de ejemplo.
- No subas datos reales de estudiantes a un repositorio público.
